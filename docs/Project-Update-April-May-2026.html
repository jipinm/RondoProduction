Foundation Work: Pricing, Currency & Email Infrastructure

February 12, 2026 & March 13, 2026 ⏱ ~98 hrs total

Before the April–May feature sprint, two significant technical deliveries established core platform infrastructure: a complete overhaul of the hospitality management model, hierarchical markup pricing, and multi-currency payment system in February, followed by a transactional email service migration from PHPMailer to SendGrid in March.

F.1 Hospitality Management — 5-Level Hierarchical Refactor ~20 hrs
🏟
5-Level Hierarchy
Refactored from a flat model to: Sport → Tournament → Venue → Event → Category. Enables precisely scoped hospitality pricing across different tournaments, venues, and event types.
🔄
Model Refactor
price_usd removed from the base hospitality service model. Pricing now managed at the appropriate hierarchy level. Database schema and admin UI updated throughout.
🗂
Assignments Table
Hospitality assignments table updated to support hierarchical linkage, with a subsequent migration adding category-level assignment support.
F.2 Hierarchical Mark-up Pricing System ~38 hrs
📐
Priority-Ordered Rules
Markup rules evaluated from most specific to broadest — event-level rules override team-level, which override tournament-level, which override sport-level. Fixed or percentage-based.
🛠
Full Admin UI
New admin management interface for configuring markup rules at each hierarchy level. Visual display showing which rules are active at each level of the sports structure.
🖥
Frontend Integration
Markup pricing applied dynamically to all ticket price displays. Correct rule resolved based on the sport, tournament, and event context of each listing.
Business Value: Different margin rules can be applied to premium events (e.g., Champions League finals) versus standard fixtures — without manual price overrides on individual tickets.
F.3 Dynamic Multi-Currency Pricing & Payment System ~26 hrs
🔒
Frankfurter API Validation
Currency creation restricted to currencies supported by the Frankfurter exchange rate API. Duplicate currency codes are prevented. Only valid, actively traded currencies can be added.
💱
Dynamic Pricing
All ticket prices across the frontend converted to the customer's selected display currency in real time using live exchange rate data.
💳
Multi-Currency Payments
Payment system updated to handle transactions in multiple currencies, passing the correct currency code and converted amount to the payment gateway.
Business Value: International customers can view prices in their local currency and complete purchases without currency ambiguity.
F.4 SendGrid Email Migration · March 13, 2026 ~14 hrs
📤
PHPMailer → SendGrid
Legacy PHPMailer dependency fully replaced with the SendGrid PHP SDK, integrated via Composer and wired into the application dependency injection container.
✍️
EmailService Rewritten
Core EmailService.php rewritten to use the SendGrid API client. Full support for HTML and plain-text bodies. Email verification and password reset emails reimplemented on the new service.
⚡
DI Container Updated
Application dependency injection container (container.php) updated to bind the new SendGrid-backed EmailService implementation throughout the application.
Business Value: SendGrid provides superior deliverability rates, delivery tracking, and spam filtering compared to direct SMTP dispatch via PHPMailer — significantly reducing the risk of confirmation emails and password reset links landing in spam.

Display Settings & Golf Navigation

Deployed April 20, 2026 ⏱ ~32 hrs

Introduced a fully configurable admin panel for controlling which content appears in the website's navigation menus, and restructured the Golf section into a tournament-level submenu.

1.1 New Admin Module: Display Settings ~18 hrs
⚽
Football Tournament Visibility
Admins select which football tournaments appear in the dropdown. Changes take effect immediately (10-minute client cache). Prevents dead-end navigation for sold-out tournaments.
🙈
Team Exclusions
Per-tournament team toggles. Full team list loaded from XS2Event API. Useful for hiding teams with no upcoming ticketed home matches.
🏅
Other Sports Visibility
Controls the "Other Sports" dropdown for sports beyond the five primary fixed items. Enables seasonal adjustments (e.g., Cricket shown only in cricket season).
1.2 Golf Navigation Restructure ~8 hrs
Before: Golf → Single link to /events?sport_type=golf
After: Golf → Dropdown with individual tournament links (e.g., The Masters, The Open Championship). Tournaments fetched dynamically from XS2Event API, cached via useGolfTournaments for 20 minutes.
1.3 Team Filtering in Navigation ~6 hrs
The raw (unfiltered) menu hierarchy is cached for 20 minutes; Display Settings filtering is applied fresh on top of the cache — ensuring admin changes reflect immediately without waiting for cache expiry.

Email Management Module

Deployed May 18, 2026 · 10 files · 2,105 lines added ⏱ ~32 hrs

Previously, all email templates were hardcoded in PHP — any change required a developer and a deployment. This phase introduces a database-driven email template system with a full admin editor.

🎫
Booking Confirmation
Sent after successful payment and booking creation
✅
Email Verification
Sent after new customer registration
🔑
Password Reset
Sent when customer requests a password reset
📧
Email Change Verification
Sent when customer updates their email address
5.1 Admin Email Editor Features ~16 hrs
💻
Three-Tab Editor
HTML (with syntax highlighting), Plain Text (fallback for non-HTML clients), and Preview (live rendered iframe as the recipient will see it).
🔖
Placeholder Reference Panel
Contextual panel showing all available {{variable}} tokens for the selected template — e.g., {{customer_name}}, {{event_name}}.
🔄
Safety Net
Active/Inactive toggle — inactive templates fall back to hardcoded defaults. Reset to Default button restores original content in one click.
5.4 Backend Email Service Upgrade
EmailService.php refactored with a new renderTemplate() method. Loads active template from database first → falls back to hardcoded template if none exists → falls back silently if DB connection fails (email still sends). All four email events flow through the unified rendering pipeline.

Conclusion

The February–May 2026 period delivered substantial functional and presentational progress across all three applications. The work transitions the platform into a polished, brand-consistent product — while simultaneously adding significant content management capabilities that reduce dependency on developer involvement for day-to-day content operations.

The February 2026 foundation work — the 5-level hierarchical hospitality model, the hierarchical markup pricing system, and the multi-currency payment integration — established the core commercial infrastructure of the platform. The March 2026 SendGrid migration replaced the legacy email delivery system with a reliable, trackable service used by all transactional communications.

The four new admin modules (Display Settings, Contact Page, SEO Management, Email Management) collectively mean that the business team can now control the website's navigation structure, contact information, search engine visibility, and customer email communications entirely through the admin panel — without requiring code changes or deployments.

The brand implementation ensures the customer experience is consistent with the RONDO 2026 visual identity across every page and interaction.
