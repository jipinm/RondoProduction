**Prepared for:** Rondo Sports  
**Date:** April 4, 2026

---

## Overview

This document outlines the agreed scope of enhancements for the Rondo Sports ticketing platform. The work covers updates to the website's navigation menu, improved control over what tournaments and teams are displayed to users, and the introduction of new admin tools to manage these settings going forward.

---

## What We Are Delivering

### 1. Football – Tournament Display Control

Currently, the Football section shows every tournament returned from the data source, with no way to control which ones appear.

**We will deliver:**
- A new admin setting that allows your team to choose exactly which football tournaments are shown on the website
- If selections are saved, only those tournaments will be displayed to visitors
- If no selections are made, the website will continue to show all tournaments as it does today — ensuring no disruption

---

### 2. Tournament – Team Filtering

Currently, all teams within a tournament are displayed without any option to hide specific ones.

**We will deliver:**
- A new admin setting that allows your team to exclude specific teams from any tournament listing
- For example, if you wish to hide two teams from the Premier League, only the remaining teams will be shown to visitors
- For tournaments with no exclusions set, all teams will continue to display as normal

---

### 3. Menu Restructure – Replace Cricket with Golf

Currently, Cricket appears as a main menu item and Golf is listed under "Other Sports."

**We will deliver:**
- Golf promoted to a main menu item, replacing Cricket
- Golf will have its own submenu listing tournaments dynamically (consistent with how the Tennis menu works today)
- Cricket moved to the "Other Sports" section
- Golf removed from the "Other Sports" section
- All links and navigation will be updated to reflect the new structure

---

## Summary of Changes

| Area | Change |
|---|---|
| Football Menu | Admin control to select which tournaments are displayed |
| Team Listings | Admin control to exclude specific teams per tournament |
| Main Menu | Cricket replaced by Golf |
| Other Sports | Cricket added; Golf removed |
| Admin Panel | New management screens for tournaments and team visibility |

---

## What Stays the Same

- All existing functionality not listed above remains unchanged
- Where no configuration is set by your admin team, the website will behave exactly as it does today
- No disruption to current bookings or user journeys
